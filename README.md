#  Gold & Currency Price Scraper

یک پروژه **Web Scraping با Python** برای دریافت قیمت لحظه‌ای طلا و ارز از سایت **TGJU**.

این برنامه با ارسال درخواست به صفحات مربوط به هر بازار، اطلاعات قیمت را از HTML صفحه استخراج کرده و به‌صورت مرتب در ترمینال نمایش می‌دهد.

##  امکانات

این پروژه قیمت موارد زیر را دریافت می‌کند:

*  دلار
*  یورو
*  طلای ۱۸ عیار
*  سکه امامی
*  انس طلا

همچنین زمان دریافت اطلاعات نیز نمایش داده می‌شود.

##  تکنولوژی‌های استفاده شده

* Python
* Requests
* BeautifulSoup
* Regular Expressions (Regex)
* Dictionary
* Functions
* `datetime`

##  کتابخانه‌ها

برای اجرای پروژه کافی است کتابخانه‌های زیر را نصب کنید:

```bash
pip install requests beautifulsoup4
```

کتابخانه‌های `re` و `datetime` جزو کتابخانه استاندارد Python هستند و نیازی به نصب جداگانه ندارند.

##  نحوه کار پروژه

فرآیند کلی برنامه به این صورت است:

```text
TGJU
  ↓
Requests
  ↓
دریافت HTML
  ↓
BeautifulSoup
  ↓
تبدیل HTML به متن
  ↓
Regex
  ↓
استخراج قیمت
  ↓
Dictionary
  ↓
نمایش اطلاعات در Terminal
```

برای هر بازار، برنامه آدرس مربوط به همان صفحه را ایجاد می‌کند و سپس قیمت آن را استخراج می‌کند.

در حال دریافت دلار...

> قیمت‌های بالا فقط نمونه هستند و هنگام اجرای برنامه، مقادیر دریافت‌شده از سایت نمایش داده می‌شوند.

##  هدف پروژه

هدف از ساخت این پروژه، تمرین عملی **Web Scraping** و کار با اطلاعات واقعی یک وب‌سایت است.

در این پروژه مفاهیمی مانند ارسال درخواست HTTP، پردازش HTML، استخراج اطلاعات با Regex، کار با Dictionary و ساخت توابع تمرین شده‌اند.

##  نکته

از آنجا که ساختار وب‌سایت‌ها ممکن است تغییر کند، در صورت تغییر HTML سایت TGJU ممکن است بخش استخراج قیمت نیاز به بروزرسانی داشته باشد.
